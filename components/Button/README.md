# Button

## Purpose

Primary, secondary, and utility actions.

## Variants

- Primary: one main page action.
- Secondary: supporting action.
- Ghost: low-emphasis action.
- Icon: compact utility action.

## Rules

- Each product screen should have one dominant primary button.
- Button labels must be action verbs.
- Minimum touch height: 44px.
- Do not use buttons for static labels.

## Accessibility

- Use native `button` elements when possible.
- Provide `aria-label` for icon-only buttons.
- Preserve visible focus states.
