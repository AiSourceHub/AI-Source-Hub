# Card

## Purpose

Reusable container for grouped content.

## Use For

- Repeated result items
- Compact panels
- Alerts or summaries

## Rules

- Border radius should stay at 8px unless there is a strong reason.
- Do not nest cards inside cards.
- Cards should contain one clear concept.

## Accessibility

- Use headings inside cards when they introduce distinct content.
- Do not rely on shadow alone to communicate grouping.
