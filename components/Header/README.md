# Header

## Purpose

Top navigation container for AI Source Hub products.

## Use For

- Product name
- AI Source Hub brand mark
- Optional language switcher
- Optional single secondary action

## Rules

- Keep the header compact.
- Do not use marketing navigation inside product tools.
- On mobile, stack only when content cannot fit.
- In Arabic, align brand and actions using RTL direction.

## Accessibility

- Use a semantic `header` element.
- Provide clear labels for icon-only actions.
- Keep focus order left-to-right in English and right-to-left in Arabic.
