# Input

## Purpose

Single-line text input for short values.

## Use For

- Names
- Email
- Short business attributes
- Numeric or compact text values

## Rules

- Use clear labels.
- Keep helper text short.
- Show validation messages near the field.
- Support Arabic and English input.

## Accessibility

- Associate every input with a visible label.
- Do not rely on placeholder text as the only instruction.
- Mark invalid states programmatically.
