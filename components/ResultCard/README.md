# ResultCard

## Purpose

Display a structured decision result.

## Use For

- Verdicts
- Risks
- Recommendations
- Improved ideas
- Product diagnostics

## Rules

- Put the decision first.
- Keep each section scannable.
- Highlight the biggest risk and next action.
- Use one recommendation, not a long list.

## Accessibility

- Use a clear heading hierarchy.
- Support `aria-live` when results appear after user action.
- Keep RTL order natural in Arabic.
