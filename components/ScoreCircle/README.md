# ScoreCircle

## Purpose

Prominent circular display for a total score.

## Use For

- Total score
- Confidence score
- Product health score

## Rules

- Always pair the number with a visible label.
- Show the denominator when space allows.
- Use semantic color based on score range.

## Accessibility

- Provide an accessible label such as "Total score: 68 out of 100".
- Do not communicate score only through color.
