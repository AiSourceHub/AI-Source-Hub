# TextArea

## Purpose

Multi-line input for short descriptions.

## Use For

- Business ideas
- Customer descriptions
- Problem statements
- Notes

## Rules

- Make short answers feel acceptable.
- Use examples only as placeholders or helper text.
- Avoid large text areas unless longer writing is expected.
- Support Arabic RTL and English LTR typing.

## Accessibility

- Use visible labels.
- Keep minimum tap area comfortable.
- Preserve browser resize behavior unless layout breaks.
