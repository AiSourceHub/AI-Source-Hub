# AI Source Hub Core Engine

The core engine is the reusable decision-engine foundation for AI Source Hub products.

It is product-agnostic, client-safe, and designed to support 20+ focused AI products.

## Modules

- `analyzer/Analyzer.js`
- `validation/ValidationEngine.js`
- `scoring/ScoreEngine.js`
- `recommendation/RecommendationEngine.js`
- `reporting/ReportBuilder.js`
- `localization/ar.js`
- `localization/en.js`
- `utils/helpers.js`

## Rules

- No product-specific logic.
- No UI.
- No backend.
- No APIs.
- No authentication.
- No databases.
