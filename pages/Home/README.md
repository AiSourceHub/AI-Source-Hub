# Home

## Purpose

Platform entry page for AI Source Hub.

## Role

Home should introduce the product library and guide users to available AI decision engines.

## Rules

- Do not behave like a marketing landing page unless the business requires it.
- Show available products clearly.
- Prioritize product discovery and quick access.
- Support Arabic and English content.
- Use mobile-first layout.

## Reusable Sections

- Header
- Hero Section
- Product list
- Why AI Source Hub
- How It Works
- Features
- Testimonials
- FAQ
- Featured product area
- Footer

## Implementation

The homepage is assembled from reusable component modules and shared design-system CSS.

Entry point: `pages/Home/index.html`
