# ProductLayout

## Purpose

Reusable page shell for individual AI Source Hub products.

## Role

ProductLayout gives every product a consistent structure while allowing the product-specific tool area to remain focused.

## Rules

- Keep the product task visible immediately.
- Use one primary action per product screen.
- Place result output near the input when possible.
- Support Arabic RTL and English LTR.
- Avoid product-specific styling inside the layout shell.

## Reusable Sections

- Header
- Product intro
- Tool surface
- Result area
- Footer
