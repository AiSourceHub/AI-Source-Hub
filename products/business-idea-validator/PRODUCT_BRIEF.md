# Business Idea Validator - Product Brief

## One Problem

Entrepreneurs often waste time on business ideas before checking whether the idea has a clear customer, painful problem, believable offer, and realistic path to revenue.

Business Idea Validator helps them decide whether an idea is worth pursuing, improving, or dropping within 10 minutes.

## Target User

Early-stage entrepreneurs, solo founders, freelancers, and small business owners who have an idea but need a fast, practical reality check.

## Core Outcome

The user receives a clear validation result:

- Pursue
- Improve
- Pause

The result includes a score, the biggest weakness, and the next best action.

## User Input

The first version should ask for only four things:

1. Business idea
2. Target customer
3. Problem being solved
4. How the business will make money

If the user does not know an answer, they can write "not sure".

## Product Flow

1. User enters the four inputs.
2. Product evaluates the idea across five criteria.
3. Product returns a simple scorecard.
4. Product recommends one next action.

## Validation Criteria

| Criterion | Question | Score |
| --- | --- | --- |
| Problem clarity | Is the problem specific and understandable? | 0-20 |
| Customer clarity | Is the target customer clearly defined? | 0-20 |
| Pain level | Is the problem urgent or expensive enough to matter? | 0-20 |
| Monetization | Is there a believable way to make money? | 0-20 |
| Differentiation | Is there a reason this solution could stand out? | 0-20 |

Total score: 100

## Result Rules

- 75-100: Pursue
- 50-74: Improve
- 0-49: Pause

## Output Format

The result should be short and decision-focused:

1. Verdict
2. Total score
3. Score breakdown
4. Biggest risk
5. Best next action
6. One-sentence improved idea

## MVP Features

- Four-field idea input
- One-click validation
- Scorecard result
- Verdict badge
- Biggest risk
- Next action
- Improved idea statement

## Features Not Included Yet

- Market research
- Competitor analysis
- Financial projections
- Business plan generation
- Long explanations
- Multi-step onboarding

## Success Metrics

- User can submit an idea in under 2 minutes.
- User receives a result in under 10 minutes.
- User understands the verdict without reading instructions.
- User leaves with one concrete next action.

## First Build Recommendation

Build a single-page web app with:

- Four input fields
- One primary action button: "Validate Idea"
- A compact scorecard result
- A copyable summary
