# New Product Checklist

Use this checklist before adding a product to the active platform.

- [ ] Copy template
- [ ] Rename folder
- [ ] Set product metadata
- [ ] Define input schema
- [ ] Define output schema
- [ ] Write isolated rules
- [ ] Add Arabic content
- [ ] Add English content
- [ ] Connect shared pipeline
- [ ] Register product
- [ ] Add route
- [ ] Add homepage metadata
- [ ] Test RTL
- [ ] Test LTR
- [ ] Test mobile
- [ ] Test desktop
- [ ] Test empty inputs
- [ ] Test weak inputs
- [ ] Test strong inputs
- [ ] Test report copy
- [ ] Test report download
- [ ] Check console
- [ ] Update documentation
